# Claude 习惯与个人技能

本应用提供接近 Claude Code 的键盘操作，并可引用使用者本机的 `~/.claude/CLAUDE.md` 与 `~/.claude/skills`。本仓库不包含个人偏好文件、私人技能正文或私人项目目录。

## 操作和显示

- 列表中 3 秒内连按两次 `Ctrl+X` 永久删除选中会话及子会话，第一次只提示，其他操作取消；输入框中保留剪切功能。
- 空输入 `←` 返回会话列表，保留原有导航习惯。
- Enter 立即回显；等待动画独立于消息更新，显示恢复、思考、执行和回复阶段。
- 状态栏按时间、Token、上下文剩余、短期额度剩余、长期额度剩余、模型排列。上下文计数使用 Codex 最近一轮用量，避免将累计账单误作上下文占用。

## 原文件引用

将自定义技能放在 `~/.claude/skills/<技能名>/SKILL.md`，或让该目录软链到原始技能目录。例如：

```text
~/.claude/skills/example-skill/SKILL.md
```

应用跟随软链解析源文件，按实际发现的元数据构造技能目录，不依赖开发者本机的技能名称或目录布局。

应用启动或 `/skills` 时读取技能元数据。每条消息附带来源索引；显式 `$技能名` 会从原文件读取最新正文，作为本次请求的应用上下文传入。模型按任务读取相关参考文件。保持单一源文件，不复制一套可能过期的技能；演示模式不读取个人资料。

本机 Codex 的原生 skill 路径参数没有展开未注册的外部技能，真实测试已确认这一点，因此这里采用正文上下文接入。

这是技能来源接入，不代表每个工作流都已完成端到端验证。Claude 专用工具名、插件和执行权限需要与当前 Codex 环境匹配，不能由说明文件自动赋予。邮件、服务器和远程任务仍以当前用户任务及实际审批为准。
